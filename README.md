# FORM Subdivision Studio 宣传片 · 第五版(节奏重调)

基于仓库 02(完整流水线)和 02-01(三维开场)。这一版只做一件事:重调整片节奏——前段收紧、后段放慢、接缝抹平。
整条片子从代码重新录制、重新渲染,**没有使用仓库里现成的 promo_720p.mp4,也没有改任何播放速度**;
配音按原来的音色和语速(zh-CN-YunxiNeural,+8%)重新合成后原样摆到新的时间点上,不变速、不变调。

## 时间表(实测)

| 段落 | 原版 | 这一版 |
| --- | --- | --- |
| 前段(到“所以,我做了这个网站”) | 28.0 s | 25.75 s |
| 后段(网站真实录屏) | 46.0 s | 60.0 s |
| 全片 | 74 s | 85.75 s |

前段受口播长度限制(四句口播共 23.3 秒),钟面时间只能收约 2 秒,提速主要靠画面:一句口播一个画面,不再一台车从头转到尾。
后段是重新录制的,整体放慢约三分之一。总时长因此变长;想压回 75 秒左右,在 `pipeline/record.mjs` 里少演示一两个参数即可。

## 改了什么

### 前段(`src/intro/`,由流水线逐帧渲染进成片)

| 镜头 | 文件 | 画面 |
| --- | --- | --- |
| A1 开场 | `film.ts` | 三维细分曲面车身只在这里亮相一次:控制笼扫出 → 加密 → 上漆,三句大字各占一拍 |
| A2 周期痛点 | `burnout.ts` | **不用车模型**。工位上的人、越转越快的钟、往里挤的四壁、一张张砸下来的“再来一版”、见底的电量,最后一头栽在键盘上;到“正常三到五天”压力才松开 |
| A3 重复的活儿 | `repeat.ts` | **不用车模型**。时间条 → 一版一版翻牌 → 蓝图上拉尺寸线 → 反复描趋势线 |
| A4 两派建模 | `schools.ts`(沿用 02-01) | 体块法 / 拼接法;“再做腰线”之后加速收拢,赶在接缝前拼成整车 |

- `pipeline/schedule.mjs`:句间空拍从约 1 秒收到 0.5–0.6 秒(`LEAD` 和各镜头留白),镜头长度只取到半拍。
- 稿子只动了一个标点:s2 里“一天一版”后面的句号换成逗号(停顿短约半秒),字和语速没变,字幕仍是原文。

### 后段(`pipeline/record.mjs`,对线上网站重新逐帧录制)

- 拖滑块的三档速度 `two / one / quick` 全部放慢,每调完一个参数多停 0.2–0.3 秒。
- 8 个标准车型连点:每个约 0.5 秒 → 约 0.8 秒。
- 各段素材时长:R0 3.1→4.0 s,R2 4.4→6.5 s,R3 12.8→17.3 s,R6 9.2→12.6 s,R7 6.5→8.4 s,R8 10.0→11.2 s。
- `pipeline/timeline/index.html`:镜头跟随光标的提前量 0.7 → 1.2 秒,切镜时的冲击和模糊收小,去掉切镜白闪。
- `pipeline/schedule.mjs`:后段口播晚半拍进。

### 接缝

- **匹配转场**(`timeline/index.html` 的 `R.B2`):A4 最后一帧(拼好的整车)朝网站视口里那台车的位置推过去并化开,浏览器窗口同时从略小处推近淡入。没有白闪,也没有空一拍的字幕卡。
- **音乐**(`pipeline/audio.mjs`):原来前段半拍速、网站登场后切到十六分琶音。现在全片同一套律动:前段四分底鼓 + 八分贝斯,登场第一小节抽掉鼓,后段琶音减成八分。
- **同一条流水线**:开场动画不再是盖在视频上的实时画布,而是和录屏一起逐帧渲染成同一个 mp4(同分辨率、帧率、压缩)。

## 重新出片

```bash
bash pipeline/setup.sh    # Debian / Ubuntu:ffmpeg、字体、Playwright Chromium、edge-tts
node build.mjs all        # 录制 → 配音 → 时间表 → 混音 → 打包开场动画 → 渲染 → 封装 → 抽帧 → 内嵌
npm run build             # 生成成片页面 dist/index.html
```

只重跑其中几步:`node build.mjs schedule audio intro web sheets embed`(不重新录制、不重新合成语音)。
中间文件默认在 `.work/`,可用 `PROMO_WORK` 指到别处。无显卡的 2 核机器上实测:两路并行录制约 11 分钟,720p 渲染约 15 分钟
(开场的三维车身走 SwiftShader 软件渲染,是最慢的一段;`build.mjs` 现在把开场和录屏分两趟渲染,录屏段不开 GPU)。

`raw/*.meta.json` 是本次录制的逐帧元数据(光标轨迹、事件、读回的真实数值);帧序列和 mp4 不随项目保存,
页面里的成片是切成 base64 文本分片(`src/generated/`)内嵌的。

## 没做的 / 需要知道的

- 只渲染了 1280×720 · 30 帧的内嵌版。1080p 和 60 帧主版本没有出(`node build.mjs hd master`),四款封面没有重做。
- 配音仍是 AI 合成语音(微软 Edge 在线朗读,不是真人录音,也不是对外授权的商用渠道)。换成自己的录音:放到 `assets/audio/<id>.wav` 后重跑 `schedule audio intro web embed`,动画节点会跟着口播走。
- 画面是通过抽帧检查的,成片没有被实际听过一遍;响度、人声/背景比来自混音脚本的实测(见页面)。
- 原版(第四版)的完整说明保留在 `output/README_v4.md`:录制方式、数值选取、字幕、响度等部分仍然适用;其中的时间、时长和“开头三张大字卡 / R1 / 封面”相关内容以本文件为准。
